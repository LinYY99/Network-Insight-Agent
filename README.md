# Network Insight - Ruijie

本仓库**只存放发布产物（Releases）**，不含源代码。
This repository hosts release artifacts only.

## 下载

最新安装包请前往 **[Releases](../../releases/latest)**。

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `Network-Insight-Ruijie-Setup-<版本>.exe` |
| macOS Intel | `Network Insight - Ruijie-<版本>.dmg` |
| macOS Apple Silicon | `Network Insight - Ruijie-<版本>-arm64.dmg` |

也可以不用手动下载：客户端启动后会自动检查本仓库的最新 Release，
发现新版本时在界面右上角提示，并可一键下载安装包到本地。

## 安装说明

- **Windows**：运行 `.exe` 安装程序，需要管理员权限（部分网络诊断功能依赖它）
- **macOS**：打开 `.dmg` 并把应用拖入「应用程序」；Apple Silicon 请选 `-arm64` 版本

## 反馈

如遇使用问题，请附带以下信息联系支持：

- 客户端版本号（界面右上角可查）
- 问题现象与发生时间
- 日志：托盘菜单 →「打开日志目录」，取其中的 `app.log`
